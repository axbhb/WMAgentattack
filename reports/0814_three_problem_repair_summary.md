## Retained architecture

The scientifically retained method is not Dreamer. It is a semantic hybrid
world-model skeleton with exact sandbox execution outside the learned model,
causal Semantic/Structured state, legal-action masking, and a learned observed
adjacent-transition module. Given state and selected action, that module
predicts the next victim action and probabilities of execution error, nonempty
output, and continuation. Utility, security, hidden state, counterfactual tool
effects, reward, actor, critic, and planner heads remain disabled.

The three-source unified dataset remains an audited resource, but ToolSandbox
and InjecAgent are not yet authorized as effective training expansion for the
AgentDojo target. The failed ontology and adapter experiments show that neither
row volume nor source labels create compatible dynamics by themselves.

## Next valid experiment

Freeze a genuinely fresh task-disjoint AgentDojo confirmation surface before
any further architecture selection. On that surface, preregister one integrated
comparison: Structured state plus source-specific final action heads plus the
retained adjacent-transition loss, against AgentDojo-only Structured dynamics
and the frozen simple pooled architecture. The current 20-task surface must not
be reused to select this candidate. If the integrated model fails, auxiliary
sources should be used for representation pretraining or source-local probes,
not claimed as target-world-model expansion.

No attack data generation, Dreamer training, large planner training, or real
external endpoint calls were performed in this repair loop.
