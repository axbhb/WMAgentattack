# v27 typed successor-evidence identifiability preregistration

v26 showed that explicit support data is useful but independent atom targets lose entity-field-tool bindings, while `matched_count=3` is not reliably extrapolated by an ordinal classifier. v27 therefore changes the target representation before another model is trained.

The model-visible target contains bound evidence records, conflicts, execution state, delta bits and pointer indices into the current trusted goal terms. Canonical effect labels are audit-only. Entity and attribute labels are rendered from bound records, source is rendered from the explicit action, and matched count is rendered from pointer cardinality.

Two byte-independent builds must reconstruct exactly 121 confirmation transitions and 10 support transitions from the frozen v17-v19 and v25 state catalogs. All v20 full effects and v21 source-filtered effects must be recovered exactly. The gate also requires zero task overlap, leakage, pointer, binding and adjacency errors; 1.0 entity, attribute and operation coverage for task-disjoint unseen mechanisms; at least one support row with count 3; and availability of count values 0, 1 and 3 in every training fold after adding support.

This is an offline CPU data gate with zero environment calls, LLM calls, model fits, GPU requests, attacks or result-driven reruns. GO authorizes only one separately preregistered small bound-successor model comparison.
